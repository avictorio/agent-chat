# Working on agent-chat (chat.victorio.cloud)

Read `AGENTS.md` in this repo root before changing anything. It is the guide
for the web app (the Android app was removed from the repo; see its section
8): ground rules, architecture, deploy workflow and the pitfalls list, and
the index of its topic files in `docs/agents/` (how each feature is built,
testing and visual checks). Open the topic file for the area you change.
